dtk-rs Widget type-mapping conventions are documented in README.md "Design": QString↔&str, enums→i32 with `dtk::qt` constants. New DCore/DGui pilot enum inputs use Rust types with C++ value getters generated from native headers; untyped enum inputs remain `unsafe`. Never guess C++ enum discriminants in Rust.
