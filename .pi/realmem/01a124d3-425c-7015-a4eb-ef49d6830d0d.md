In dtk-rs, all application constructors must run on the Linux process main thread. Create `DApplication` before allocating any GUI QObject/QWidget. GUI constructors must check both that the application exists and that the caller is on QApplication's GUI thread before Qt allocation. GUI wrappers must still reject headless QCoreApplication runtimes.
