dtk-rs separates Rust-facing wrappers in `dtk/` from the unsafe FFI layer in `dtk-sys/` (`links = "dtk6widget"`). `dtk/src/lib.rs` contains hand-written core classes; `dtk/src/application.rs` implements scoped headless QCoreApplication. `dtk-sys/src/lib.rs` is hand-written cxx::bridge #1; `dtk-sys/src/{gen,core,gui}_ffi.rs` are generated bridges #2-4 for Widget, DCore and DGui. `dtk-sys/cpp/` contains hand-written `shim.cpp/core_application.cpp`, generated `dtk_{gen,core,gui}_shim.cpp`, and `relay.cpp`; `dtk-sys/include/` contains headers. `relay.h` has Q_OBJECT and needs moc. `dtk-sys/build.rs` uses pkg-config Qt6/DTK6, runs moc, and builds C++ with c++17 + -fPIC. `TODO.md` records known gaps; `ARCHITECTURE.md` describes layers, type mapping and signal/lifetime design. `tools/gen.py` scans DWidget headers plus selected DCore/DGui pilot headers; `dtk/src/widgets.rs` covers 146 DTK Widget classes, while `dtk/src/core.rs` and `src/gui.rs` are generated audited pilots (3 DCore, 3 DGui). Generator-owned files — `dtk/src/{widgets,core,gui}.rs`, `dtk-sys/src/{gen,core,gui}_ffi.rs`, `dtk-sys/cpp/dtk_{gen,core,gui}_shim.cpp`, `dtk-sys/include/dtk_{gen,core,gui}_shim.h`, and all `GEN*REPORT.md` — must be regenerated, not hand-edited; `GEN_REPORT.md / GEN_CORE_REPORT.md / GEN_GUI_REPORT.md` are per-domain coverage reports whose DCore/DGui pilot counts do not describe the full libraries. New DTK methods should usually be added through `tools/gen.py` and regeneration, not handwritten bindings; methods whose parameter types are unmapped (other QList types, `QPrinter*`, ...) remain skipped and are recorded in the corresponding domain `GEN*REPORT.md` — coverage reports document unsupported signatures rather than implying complete bindings. Hand-written additions belong in `dtk/src/lib.rs` / `dtk-sys/src/lib.rs` + `cpp/shim.cpp`, not in generator-owned output. Build and regenerate bindings with `cargo build` (build all) and `uv run --no-project python tools/gen.py && cargo build` (regenerate bindings); keep generator output reproducible — regeneration is required when changing generator coverage. Regression checklist: `uv run --no-project python -m unittest tools.test_gen` and `cargo test --workspace --all-targets`; run examples offscreen with `QT_QPA_PLATFORM=offscreen`: `demo --smoke`, `mpsc_eventfd --smoke`, `paint_widget --smoke`, `dialog_selfcheck`, `lifetime_selfcheck`, `threading_selfcheck`, `opaque_lifetime_selfcheck`, `layout_selfcheck`, `variant_selfcheck`, `action_selfcheck`, `model_selfcheck`, `no_application_selfcheck`, `owned_selfcheck`, `ownership_transfer_selfcheck`, `image_selfcheck`, `value_types_selfcheck`, `table_header_selfcheck`, `signal_reentrancy_selfcheck`, `core_paths_selfcheck`, `gui_helper_selfcheck`, `gui_image_selfcheck`, `gui_font_selfcheck`, `config_selfcheck`; also `cargo run -p dtk-sys --example guard_selfcheck` offscreen; run `core_application_selfcheck` with DISPLAY/WAYLAND_DISPLAY/QT_QPA_PLATFORM unset. GUI demo: `cargo run --example demo`; headless smoke test: `QT_QPA_PLATFORM=offscreen ./target/debug/examples/demo --smoke`.
