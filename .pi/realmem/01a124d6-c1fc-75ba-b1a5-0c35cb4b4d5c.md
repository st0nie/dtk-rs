In dtk-rs, connect signals via `connect_signal*` / typed helpers. Qt object destruction releases Rust callbacks automatically; `dtk::unregister_callback(id)` disconnects early. Never touch the global relay map from worker threads: worker `unregister_callback` is a no-op for GUI-owned ids, so a Send callback id must not permit off-thread access to Qt's GUI-owned relay registry. Nested emission of the same signal queues copied arguments until the outer `FnMut` invocation returns; cancellation discards queued invocations. Dispatch must never alias mutable callback borrows (`&mut`) during reentrant Qt signal emission.
