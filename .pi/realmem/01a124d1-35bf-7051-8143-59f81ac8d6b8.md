dtk-rs provides Rust bindings for DTK6 (dtkwidget) so deepin applications can use DTK UIs in pure Rust. It requires Linux with Qt6 + DTK6 development packages; pkg-config must find `Qt6Widgets`, `dtk6widget`, etc. The project is not cross-platform.
