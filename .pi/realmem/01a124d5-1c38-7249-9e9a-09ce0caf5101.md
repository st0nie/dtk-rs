dtk-rs has four cxx bridges: hand-written core plus Widget, DCore and DGui pilots. Generated QObject/QWidget base pointers are adjusted by C++ `static_cast` before `as _` pointer casts across bridges; this boundary is audited in `tools/gen.py`. Never guess QWidget ancestry by a class name or prefix: only verified ancestry can justify QObject/QWidget base conversions.
